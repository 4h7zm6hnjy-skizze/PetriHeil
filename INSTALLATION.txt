PetriHeil Pro Update v2.0.36 – Jahresbericht und Fangfotos

1. Bitte in PetriHeil Pro unter Backup vorab eine Datensicherung erstellen.
2. Die ZIP auf dem iPhone entpacken.
3. Nur die 8 APP-Dateien im Archiv (ohne diese Anleitung) direkt in das Hauptverzeichnis auf GitHub hochladen; vorhandene Dateien ersetzen.
4. Commit changes speichern; GitHub Pages abwarten.
5. PetriHeil-App online zweimal öffnen.
6. In Angelzentrale > Fangbuch Pro, Cockpit oder Backup auf „Jahresbericht öffnen“ tippen.
7. Jahr und Datenschutz wählen. PDF oder CSV speichern.

Wichtig: Originalfangbuch bleibt unverändert. Keine Cloud-Synchronisierung. PDFs enthalten keine Fotos.
